# Правила для AI-агентов

## Назначение

Репозиторий хранит маленькое TypeScript-ядро виджетов Portable Agent.

## Границы

- Не добавляй React, Telegram SDK, HTTP client или состояние диалога в core.
- Не меняй файл в `contracts/` вручную: сначала выпусти контракт в `portable-agent/contracts`.
- Не создавай `actionId` и `payloadHash`; SDK получает их от backend.
- Не придумывай текст, риск и правила подтверждения.
- Не включай исходную карточку в текст ошибки: в ней могут быть личные данные.

## Правила работы

1. Пиши документацию по-русски, имена в коде — простым английским.
2. Используй TDD: падающий тест → минимальный код → упрощение.
3. Отступ — четыре пробела, tab запрещён.
4. Generated type не редактируй вручную; запускай `pnpm generate`.
5. Обновляй README, SERVICE и TechDocs вместе с изменением границы.
6. Перед завершением запускай `pnpm lint`, `pnpm test`, `pnpm typecheck` и `pnpm pack:check`.
