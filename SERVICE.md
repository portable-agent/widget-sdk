# Паспорт Widget SDK

## Ответственность

Библиотека проверяет карточку подтверждения и общий виджет подключения. Она даёт одинаковую границу
Web и адаптерам мессенджеров. Для карточки подтверждения библиотека создаёт команду решения.

## Не входит в ответственность

- HTTP, JWT и хранение token;
- состояние диалога;
- создание или выполнение action;
- React, Telegram, VK и другой конкретный renderer;
- выбор текста, риска или необходимости подтверждения.

## Вход и выход

Вход — неизвестный JSON по одной из опубликованных JSON Schema. `parseCard` возвращает карточку
подтверждения или `CardError`. `parseConnection` возвращает виджет подключения или `WidgetError`.
`makeDecision` возвращает `actionId`, `payloadHash` и `CONFIRM/CANCEL`, но ничего не отправляет по сети.
SDK не вызывает Action Service напрямую и не открывает OAuth URL.

## Контракт
