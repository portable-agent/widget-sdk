# ADR-0001: Ядро не зависит от renderer

- Status: accepted
- Date: 2026-09-14

## Контекст

Web, Telegram и VK показывают кнопки по-разному, но подтверждают одно сохранённое действие.

## Решение

Widget SDK проверяет общий JSON и создаёт decision command. React components и адаптеры мессенджеров
живут в отдельных пакетах или репозиториях и зависят от core.

## Последствия

- core остаётся маленьким и переносимым;
- канал сам выбирает визуальное представление;
- безопасность `actionId + payloadHash` тестируется один раз;
- готовый экран Web появится в отдельном пакете после согласования UX.
