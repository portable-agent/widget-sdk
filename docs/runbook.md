# Runbook

## Карточка отклонена

Проверьте `CardError.issues`, версию контракта и тип ответа Conversation Service. Не записывайте всю
карточку в log: поля могут содержать личные данные.

## Generated type изменился

Убедитесь, что schema взята из опубликованного release. Если изменение ожидаемо, обновите тесты и
версию контракта. Если нет — восстановите снимок из release bundle.

## Package не собирается

Запустите `pnpm generate`, затем `pnpm typecheck`. Node.js должен соответствовать версии из
`package.json`; основная проверка выполняется в CI на Node 24.
